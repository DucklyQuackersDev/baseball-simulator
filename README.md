# Baseball Simulation
Simple Baseball game simulation

## Getting Started
This project was built in python 3.14 and is required to run this file

## Installing
Follow the steps below:

1. Download the zip files from this repository 

2. Unzip project files into a designated folder

3. Open terminal and navigate to file location

4. type "python baseball.py" in cmd to run

## Current Features
- Simple game simulation with working base running mechanics and score tracking
- Simplified teams with no lineups or positions

## Upcoming Features
- Team Lineups with basic player functionality
- Player stats (speed, strength, fielding)

- errors
- better baserunning functionality (stolen bases, 1st to 3rd on singles, etc)
